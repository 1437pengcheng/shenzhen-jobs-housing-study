## 内容说明

本研究基于多源数据（行政区划 GeoJSON、房价行情网、住建部通勤监测报告、百度地图、手机信令数据），通过 Python 可视化分析深圳市产住分离的空间格局与通勤特征。

## 主要发现

- 南山区房价 95,285 元/㎡，坪山区仅 25,826 元/㎡，比值超 3:1
- 大鹏新区工作日通勤 90 分钟，南山区仅 25 分钟
- 早高峰南山人口暴增 212.5%，龙岗流失 60%
- 房价梯度与通勤时间梯度呈高度负相关

## 技术栈

Python, matplotlib, pandas, GeoJSON, Chart.js, Tailwind CSS
